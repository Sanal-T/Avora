# Avora ERP

Planning workspace for a modular ERP system covering enquiries, design, quotations, production and feedback, and labour management.

## Project status

Requirements intake and architecture planning. The initial scope and technology choices are proposals from the project brief and still need business validation. Application code has not started.

## Working approach

Validate the business workflows and open questions first. Then document and review the architecture, data model, APIs, security, reporting, operations, and delivery roadmap before starting implementation.
